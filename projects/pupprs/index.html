Pupprs

The social network where every account is a dog.

Owners make a profile for each dog, then post photos, videos and stories as that dog. They follow other dogs, chat in DMs and group chats, and join community discussions. One app for iOS, Android and the web, on a serverless AWS backend I designed, built and run.

AWhat it does

1Dogs are the accounts

People follow dogs, not other people. One person can run several dogs, and a dog can have co-owners: a couple, a family or a dog walker, with an invite and accept flow.

2Posts, reels and stories

Photo and video carousels, a GPU photo editor with filters and non-destructive edits, a video trimmer, drafts, and 24-hour stories with text, stickers and drawing.

3Real-time messaging

One-to-one and group DMs over WebSockets, with message requests, read receipts, mute and admin roles. Push notifications deep-link to the right screen.

4Explore and Discuss

A ranked global feed that blends engagement with recency decay, hashtag pages, typo-tolerant search, and a community forum with threads and polls.

5Your dog, as a cartoon

Snap a photo and a vision model reads breed, build, coat and markings. That drives a dog drawn entirely in code: one SVG rig, tuned per breed, with six coat patterns and unlockable accessories.

6Dogs only, and safe

Every report goes to a multimodal AI moderator that enforces the dogs-only rule and the safety rules. When it isn't sure, it escalates to a human instead of removing.

BSchematic

One TypeScript monorepo, five packages. Zod schemas are shared by the app and the API, so validation is identical on both sides.

CDetails

Detail C1 · Cutting RDS Proxy

Lambdas talk to Postgres directly with a pool of exactly one connection per warm container. Idle reaping on the server and an alarm on connection count keep it inside a micro instance. That, a NAT instance instead of a NAT Gateway, and tight log and trace sampling keep the bill near $50 a month.

Detail C2 · Moderation that resists prompt injection

User captions are untrusted input to an LLM. They go in delimited blocks, and delimiter sequences inside them are neutralised, so a crafted caption can't break out and inject instructions or fake a verdict.

Detail C3 · One ID from tap to database

Every request carries a correlation ID. A Sentry error in the browser links to every Lambda log line it caused with one paste into Logs Insights.

Detail C4 · Alarms that file their own tickets

CloudWatch alarms open labelled GitHub issues, fold flapping alarms into one thread, and close the issue when the alarm clears. A backstop alarm emails if the bridge itself breaks.

Detail C5 · Built with AI agents

Features are built with Claude Code. Every pull request gets four parallel AI reviews (security, scalability, code quality and a user persona) and ships with a Playwright test run against the deployed stack.
