The app

Dogs are the main characters.

People follow dogs, not other people. One person can run several dogs, and a dog can have co-owners: a couple, a family or the dog walker.

Posts, reels and stories

Photo and video carousels, a GPU photo editor with filters and non-destructive edits, a video trimmer, drafts, and 24-hour stories with text, stickers and drawing.

Real-time messaging

One-to-one and group DMs with message requests, read receipts and mute. Push notifications open the right screen.

Explore and Discuss

A ranked feed of the best posts right now, hashtag pages, typo-tolerant search, and a community forum with threads and polls.

Your dog, as a cartoon

Snap a photo and AI reads the breed, coat and markings, then draws your dog in code. Dress it up with collars, bandanas and hats you unlock by posting.

Dogs only, and safe

Every report goes to an AI moderator that keeps things on-topic and safe. When it isn't sure, a human makes the call.

Shared dogs

Invite co-owners to a dog's profile so everyone who loves that dog can post as it.

Under the hood

Production-grade, startup-cheap.

I designed, built and run Pupprs on my own: a TypeScript monorepo with a universal Expo app, a serverless AWS backend, and all infrastructure in CDK.

Cutting RDS Proxy

Lambdas talk to Postgres directly with a pool of one connection per warm container. Idle reaping and a connection alarm keep it inside a micro instance, which, with a NAT instance and tight log sampling, keeps the bill near $50 a month.

Moderation that resists prompt injection

Captions are untrusted input to an LLM. They go in delimited blocks with delimiter sequences neutralised, so a crafted caption can't inject instructions or fake a verdict.

A dog drawn entirely in code

A vision model returns breed, coat and markings as strict JSON. That drives one parametric SVG rig, tuned per breed, with six coat patterns and no image assets.

One ID from tap to database

Every request carries a correlation ID, so a Sentry error in the browser links to every Lambda log line it caused with one paste into Logs Insights.

Alarms that file their own tickets

CloudWatch alarms open labelled GitHub issues, fold flapping alarms into one thread, and close the issue when the alarm clears.

Built with AI agents

Features are built with Claude Code. Every pull request gets four parallel AI reviews and ships with Playwright tests run against the deployed stack.
