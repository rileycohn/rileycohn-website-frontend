How Pupprs is built.

A universal Expo app for iOS, Android and the web, on a serverless, event-driven AWS backend. Everything is TypeScript, from the screens to the infrastructure.

Architecture

Every path through the system.

Requests go through CloudFront to one Lambda per domain. Anything slow or fan-out happens asynchronously on queues and events, and every queue has a dead-letter queue with alarms.

Design notes

A few decisions worth explaining.

Moderation that resists prompt injection

Captions are untrusted input to an LLM. They go in delimited blocks with delimiter sequences neutralised, so a crafted caption can't inject instructions or fake a verdict. When the model isn't sure, it escalates to a human.

A dog drawn entirely in code

Bedrock returns breed, coat and markings as strict JSON. That drives one parametric SVG rig, tuned per breed, with six coat patterns and no image assets.

One ID from tap to database

Every request carries a correlation ID, so a Sentry error in the browser links to every Lambda log line it caused.

Alarms that file their own tickets

CloudWatch alarms open labelled GitHub issues, fold flapping alarms into one thread, and close the issue when the alarm clears.

Built with AI agents

Features are built with Claude Code. Every pull request gets parallel AI reviews for security, scalability, code quality and user experience, and ships with an end-to-end test.

Least privilege everywhere

Each Lambda gets only the permissions it needs: Bedrock access to one model, S3 access to specific prefixes, uploads scoped to the caller and checked by file signature.
